# 🎓 Roll Call — Student & Teacher Attendance System

A clean, colorful, browser-based attendance register built for schools and colleges. Track students, teachers, and daily attendance — no backend, no database, no setup. Just open it and start marking attendance.

## ✨ Features

| Feature | What it does |
|---|---|
| 🎓 **Students** | Add, edit, search, and view every enrolled student along with their overall attendance % |
| 🧑‍🏫 **Teachers** | Add, edit, search, and track faculty attendance the same way |
| ✅ **Take Attendance** | Mark each student Present / Absent for any date, with "mark all" shortcuts |
| 📋 **Teacher Attendance** | Same quick workflow, built for faculty |
| 🚩 **Absentees** | Instantly see who was missing on any given date — students and teachers side by side |
| 📊 **Reports** | Visual attendance percentage bars for everyone, at a glance |

---

## 🛠️ Built With

A single self-contained file — pure **HTML, CSS, and JavaScript**. No frameworks, no build step, no server required. Attendance data is stored in the browser's `localStorage`, so records persist between visits on the same device.

---

## 🚀 Running Locally

```bash
# Clone the repo
git clone https://github.com/your-username/student-attendance-system.git

# Open it
cd student-attendance-system
```

Then either:
- Double-click `index.html` to open it in your browser, **or**
- Open the folder in VS Code and click **"Go Live"** with the Live Server extension for auto-reload while editing

---

## ☁️ Deployment

This is a static site, so it deploys instantly on **[Vercel](https://vercel.com)**:

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **Add New → Project**
3. Import this repository and hit **Deploy**

No build settings needed — it's plain HTML, live in seconds.

---

## 📌 Notes

- All data lives in the browser's local storage, so it's per-device — clearing browser data resets it
- A few demo students and teachers are seeded automatically on first run — edit or remove them anytime from the Students / Teachers tabs
